# 🎓 Educational ERP Management System

## 📌 Project Overview

The Educational ERP Management System is a web-based application developed to simplify and manage college administrative activities through a centralized platform.

The system provides an organized way to manage student information, staff details, academic activities, digital certificates, and scholarship-related processes.

## 🎯 Project Objectives

* To simplify college administration.
* To maintain student and staff information.
* To manage academic activities efficiently.
* To provide digital certificate management.
* To simplify scholarship management.

## 📚 Main Modules

### 1. College ERP Management

* Student Management
* Staff Management
* Department Management
* Course Management
* Subject Management
* Exam Timetable Management
* Circular and Event Management

### 2. Digital Certificate Management

* Certificate Upload
* Certificate Storage
* Certificate Search
* Certificate View and Download
* Bonafide Certificate Request
* Conduct Certificate Request

### 3. Scholarship Management

* Scholarship Information
* Student Scholarship Requests
* Scholarship Details Management

## ⚙️ Installation and Setup

1. Clone or download this repository.

2. Open the project folder in Visual Studio Code.

3. Install the required packages:

   `pip install -r requirements.txt`

4. Create a MySQL database.

5. Configure your local database credentials using a `.env` file.

6. Run the application:

   `python app.py`

7. Open the application in your web browser.
